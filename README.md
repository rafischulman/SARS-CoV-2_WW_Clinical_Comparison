# SARS-CoV-2_WW_Clinical_Comparison

**Version:** v1.0.0

**Short description:** Analysis code and derived data for a statewide comparison of wastewater-based and clinical SARS-CoV-2 genomic surveillance in New York State, 2023–2025.

---

## Project Overview

This repository accompanies the manuscript *"Wastewater genomic surveillance detects SARS-CoV-2 variants earlier and more comprehensively than clinical sequencing: a statewide systems comparison in New York, 2023–2025."*

Using three years of paired wastewater and clinical sequencing data from New York State, the analysis compares the two surveillance modalities on: concordance of detected lineages over time, timing of first detection (lead/lag time), richness of detected genomic diversity, and how wastewater relative-abundance sensitivity thresholds and taxonomic aggregation each affect all of the above. The code reproduces every figure and results table in the manuscript and its supplement.

**Date of latest release:** 2026-08-04

### Data Availability

**Wastewater sequencing and concentration data**, **NY State COVID-19 testing data**, the **county shapefile**, and the **lineage taxonomy key** are included directly.

**Clinical sequencing data (GISAID).** This repository does **not** include the raw GISAID clinical sequencing export (`DATA/GISAID_Clinical.txt.gz`), per GISAID's Database Access Agreement. The exact set of clinical records used in this analysis is identified by:

- **GISAID EPI_SET ID:** `EPI_SET_260731fw`
- **DOI:** [https://doi.org/10.55876/gis8.260731fw](https://doi.org/10.55876/gis8.260731fw)

Researchers with an approved GISAID account can retrieve the exact record set via the EPI_SET ID above, or request the raw export directly from the corresponding author (subject to the requester independently holding a valid GISAID account/agreement). See [Contact information](#contact-information).

Instead of the raw file, `DATA/` includes small **derived aggregate tables** (`clinical_lineage_daily_counts.csv.gz`, `clinical_county_counts.csv`) containing only count/date aggregates — no per-specimen data, no accession numbers — sufficient to fully reproduce every clinical-sequencing figure and table without requiring GISAID access. **These files are already included in this repository, so running the analysis does not require GISAID access or regenerating them.** `prepare_clinical_aggregates.py`, the script that originally produced them from the raw GISAID export, is included only for transparency about that process (see Usage below).

## Installation

1. Clone this repository.
2. Install a Python environment with the dependencies listed below (a virtual environment, e.g. via `venv` or `conda`, is recommended so this project's dependency versions don't conflict with others on your system).
3. No further setup is required — the derived clinical data files needed to run the analysis are already included in `DATA/`.

**System requirements:** No specific operating system or hardware dependencies; developed and tested on macOS 14.5 with Python 3.9.12.

**Dependencies:**

```
pandas
numpy
matplotlib
scipy
geopandas
scikit-learn
```

**Please Note:** `prepare_clinical_aggregates.py` (included for transparency only, see Usage) expects the raw GISAID export's column names and date formats to match the standard EpiCoV metadata export as of this study's data pull; a future GISAID format change could require updates to its parsing logic.

## Usage

### Running the analysis

The included derived clinical data files are sufficient to reproduce every figure and table in the manuscript — no GISAID access is required.

```bash
cd SCRIPTS/
python3 wastewater_clinical_comparison.py
```

This generates every figure (`FIGURES/`) and results table (`RESULTS/`) in the manuscript and its supplement.

### Optional: regenerating the derived clinical data files

`prepare_clinical_aggregates.py` is included for transparency about how the derived files in `DATA/` were produced from the raw GISAID clinical export — **it does not need to be run to reproduce the manuscript's figures or tables.** It is relevant only to a researcher with GISAID access to the cited EPI_SET who wants to regenerate the derived aggregate files from scratch:

```bash
cd SCRIPTS/
python3 prepare_clinical_aggregates.py   # raw GISAID export -> derived aggregate tables in DATA/
```

It expects the raw export saved as `DATA/GISAID_Clinical.txt.gz` (tab-separated, gzip-compressed, in the standard GISAID EpiCoV metadata export format), and filters to the study period, deduplicates exact-duplicate records, and excludes confirmed non-NY specimens before aggregating (see the script's own docstring for details and rationale).

### Expected outputs

**Figures** (`FIGURES/`): sampling timelines, cumulative unique-lineage curves, lineage overlap and relative-abundance concordance, taxonomic aggregation proportion, lead-time violin plots, lineage emergence across cutoffs, Cohen's kappa distribution, and clinical/wastewater lineage heatmaps — each also available as a multi-cutoff supplementary version where applicable.

**Results tables** (`RESULTS/`): `cohen_kappa_top10.csv` / `cohen_kappa_top50.csv` / `cohen_kappa_all_shared.csv`, `ww_clinical_timing_table.csv` / `ww_clinical_timing_summary.csv`, `lineage_emergence_dates.csv`, `lineage_observation_table.csv`, `total_lineage_observations.csv`, `Supp1_lineage_detection_counts_and_first_dates.csv` (taxonomically aggregated), `Supp2_lineage_detection_counts_and_first_dates_unaggregated.csv` (raw, pre-aggregation).
